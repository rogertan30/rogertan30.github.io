# 拼拼哆 - 艺术拼图游戏

## 🎮 游戏简介

**拼拼哆**是一款精美的艺术拼图游戏，将经典艺术作品与趣味拼图玩法完美结合。通过拼装世界名画、国画人物、复古油画等精美图片，让玩家在享受拼图乐趣的同时，感受艺术的魅力。

## ✨ 核心特色

### 🎨 丰富的艺术主题
- **世界名画系列**：包含梵高、莫奈、维米尔等大师经典作品
- **国画人物图集**：展现中国传统绘画的独特魅力
- **复古油画系列**：体验古典艺术的优雅与精致
- **好忙小镇绘本**：7个不同主题的生活场景拼图

### 🧩 多样化难度设计
- **简单模式**：125块以下，适合新手入门
- **中等模式**：125-250块，挑战适中
- **困难模式**：250块以上，考验耐心与技巧

### 🎯 智能游戏体验
- **进度保存**：支持游戏进度自动保存，随时继续
- **提示系统**：提供拼图提示，帮助玩家突破难关
- **音效反馈**：丰富的音效设计，增强游戏沉浸感
- **多语言支持**：支持中文、英文等多种语言

## 🏛️ 主题分类详解

### 1. 好忙小镇绘本系列
- **我们的城市**：地标交错，昼夜不息，描绘都市多元风貌

## 🎮 游戏玩法

### 基础操作
1. **选择主题**：从丰富的主题分类中选择喜欢的拼图
2. **选择难度**：根据个人水平选择合适的拼图块数
3. **开始拼图**：拖拽拼图块到正确位置
4. **完成挑战**：将所有拼图块正确放置完成作品

### 高级功能
- **我的图片**：保存个人喜爱的拼图作品
- **进度管理**：查看和管理未完成的拼图
- **成就系统**：完成不同难度获得成就奖励
- **分享功能**：将完成的拼图分享给朋友

## 🎵 音效设计

游戏配备专业的音效系统：
- **puzzle_select.mp3**：选择拼图块音效
- **puzzle_placed.mp3**：放置拼图块音效
- **puzzle_completed.mp3**：完成拼图庆祝音效
- **puzzle_size.mp3**：调整拼图尺寸音效
- **tabbar_click.mp3**：界面切换音效
